КОПИЛКА ПРИЗОВ — версия 14

УСТАНОВКА / ОБНОВЛЕНИЕ
1. Распакуйте архив.
2. Загрузите все файлы из архива в корень GitHub-репозитория kopilka-prizov, заменив файлы с теми же именами.
3. Нажмите Commit changes и дождитесь публикации GitHub Pages.
4. Откройте приложение на каждом телефоне и нажмите кнопку «↻ Обновить». При необходимости полностью закройте и снова откройте приложение.

ПЕРВЫЙ ЗАПУСК И РОЛИ
После входа выберите роль «Папа» или «Сын». Для перехода в режим папы требуется пароль. Роль и данные хранятся отдельно на каждом устройстве.

ВЕРСИЯ ПАПЫ
Создание кодов, редактирование каталога призов и импорт/экспорт данных доступны в режиме папы. Для передачи данных на устройство сына используйте предусмотренный в приложении экспорт и импорт.

ВЕРСИЯ СЫНА
Доступны копилка и игры. Родительские разделы скрыты. Игровые баллы можно обменивать на коды билетов согласно правилам приложения.

ИГРЫ ВЕРСИИ 14
- Добавлены отдельные режимы изучения черногорского, английского и итальянского языков с переводом на русский.
- В раунде отображаются 10 карточек: 5 русских и 5 иностранных. По мере нахождения пар на освободившихся местах появляются новые карточки; расположение оставшихся карточек не перемещается.
- В раунде 7 пар и 2 жизни. После второй ошибки раунд проигран.
- За 10 раундов подряд без ошибок начисляется подсказка. Подсказки накапливаются и расходуются только при использовании.
- Прогресс изучения слов сохраняется отдельно для каждого языка. Слово перестаёт попадать в новые раунды после двух успешных подборов.
- Если в выбранном языке временно недостаточно слов для нового раунда, приложение сообщает об этом и предлагает выбрать другой язык.

СОХРАННОСТЬ ДАННЫХ И ОГРАНИЧЕНИЯ
Ключ локального хранилища приложения сохранён: kopilka-family-v2. При обычном обновлении через GitHub Pages локальные данные на телефонах должны сохраниться. Не очищайте данные сайта/приложения и не удаляйте его хранилище.

Приложение работает автономно и хранит данные отдельно на каждом устройстве. Данные между устройствами автоматически не синхронизируются. Пароль папы хранится на устройстве в виде хеша и защищает интерфейс от случайного доступа; это не серверная аутентификация и не шифрование данных.
