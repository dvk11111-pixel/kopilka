КОПИЛКА ПРИЗОВ — версия 15

УСТАНОВКА / ОБНОВЛЕНИЕ
1. Распакуйте архив.
2. Загрузите все файлы в корень GitHub-репозитория kopilka-prizov, заменив файлы с теми же именами.
3. Нажмите Commit changes и дождитесь публикации GitHub Pages.
4. Откройте приложение на телефоне и нажмите «↻ Обновить». При необходимости полностью закройте и откройте PWA.

ЧТО ИЗМЕНЕНО В v15
- В обычной игре слова в колонках русского и изучаемого языка перемешиваются независимо. Позиция слова больше не подсказывает позицию его перевода.
- Каждый пятый раунд — специальный: вместо поиска пар нужно вставить пропущенное слово в предложение, выбрав один из вариантов.
- Специальные раунды добавлены для черногорского, английского и итальянского языков.
- В специальных раундах пять предложений; сохраняется правило двух жизней. За успешное прохождение начисляется обычный игровой балл.
- Подсказки для парной игры в специальных раундах отключены.
- Версия кэша сервис-воркера обновлена до v15.

ДАННЫЕ
Ключ локального хранилища kopilka-family-v2 не менялся. Существующие призы, билеты, коды, очки и прогресс должны сохраниться при обычном обновлении на том же устройстве. Для безопасности рекомендуется сделать резервную копию в разделе «Данные» перед обновлением.

ОГРАНИЧЕНИЯ ПРОВЕРКИ
JavaScript и сервис-воркер проверены на синтаксические ошибки. Полное тестирование на реальном телефоне не выполнялось.
