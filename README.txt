КОПИЛКА ПРИЗОВ — версия с родительскими кодами

Возможности:
- Папа загружает каталог призов.
- Папа создаёт коды, каждый код выдаёт заданное количество билетов на выбранный приз.
- Сын импортирует файл кодов, вводит код и получает билеты.
- Сын может копить билеты, видеть прогресс и забирать награды.
- Каталог, коды и полная резервная копия экспортируются отдельно.

ВАЖНО: эта версия автономная, без сервера. Чтобы передать коды:
1. На телефоне папы загрузите каталог и создайте коды во вкладке «Папа».
2. В этой же вкладке нажмите «Скачать список кодов».
3. Передайте JSON-файл сыну (например, через мессенджер).
4. На телефоне сына импортируйте каталог через «Данные» → «Импортировать каталог JSON».
5. Там же импортируйте файл кодов папы.
6. Сын открывает «Копилка», вводит код и нажимает «Получить билеты».

Публикация для установки PWA:
1. Распакуйте ZIP и загрузите все файлы в корень репозитория GitHub.
2. GitHub → Settings → Pages → Deploy from a branch → main → /(root) → Save.
3. Откройте опубликованный HTTPS-адрес в Chrome на Android → ⋮ → «Установить приложение».

Ограничение: код активируется одноразово на конкретном телефоне, но автономная версия не может проверить, не был ли он активирован на другом устройстве. Для строгой одноразовости, мгновенной передачи кодов и общей синхронизации между телефонами нужен сервер с базой данных. Кодовый JSON содержит коды, поэтому передавайте его только сыну.


ЗАЩИТА РОДИТЕЛЬСКИХ РАЗДЕЛОВ:
- Вкладки «Папа», «Призы» и «Данные» защищены PIN-кодом 2580.
- PIN нужно вводить при каждом открытии этих разделов.
- Чтобы изменить PIN, откройте index.html в текстовом редакторе и замените 2580 в строке const PARENT_PIN='2580'. Затем загрузите обновлённый index.html в GitHub.
- Это защита от случайного доступа, а не полноценная серверная безопасность: PIN встроен в клиентский код и технически может быть найден человеком, который умеет просматривать исходный код.
