КОПИЛКА ПРИЗОВ — две версии приложения

УСТАНОВКА / ОБНОВЛЕНИЕ
1. Распакуйте архив.
2. Загрузите все файлы в корень GitHub-репозитория kopilka-prizov, заменив файлы с теми же именами.
3. Нажмите Commit changes и дождитесь публикации GitHub Pages.
4. Откройте приложение на каждом телефоне и нажмите кнопку «↻ Обновить» вверху экрана. Приложение проверит новую версию, установит её и перезапустится. При необходимости полностью закройте и откройте PWA.

ПЕРВЫЙ ЗАПУСК
На каждом устройстве выберите версию:
- «Версия папы»: при первом входе придумайте пароль (минимум 4 символа). При следующих запусках пароль будет запрашиваться снова.
- «Версия сына»: доступны копилка и игры; родительские разделы скрыты.
Выбор роли сохраняется отдельно на каждом устройстве.

ВЕРСИЯ ПАПЫ
Создание кодов, редактирование каталога и импорт/экспорт данных доступны только в версии папы. Чтобы передать каталог, экспортируйте JSON в разделе «Данные» и отправьте файл на устройство сына.

ВЕРСИЯ СЫНА
В разделе «Копилка» импортируйте каталог призов от папы. В разделе «Игры» доступна игра подбора пяти пар черногорских и русских слов. На все пять пар даётся 6 попыток (каждая ошибочная пара отнимает одну попытку). Ошибка не сбрасывает накопленный игровой прогресс: после проигрыша начинается следующий раунд. В пределах любых 10 последовательных раундов подбор обеспечивает не менее 20 различных слов. Слово, которое было правильно подобрано без ошибки в трёх отдельных раундах, больше не появляется. За все 5 правильных пар начисляется 1 балл. За 10 баллов можно создать локальный код билета; введите его в поле на экране «Копилка».

ВАЖНЫЕ ОГРАНИЧЕНИЯ
Приложение работает автономно и хранит данные отдельно на каждом устройстве. Коды, созданные папой, по-прежнему нужно передавать сыну вместе с JSON-файлом кодов. Игровой код создаётся и проверяется непосредственно в версии сына и не требует генерации в версии папы.
Пароль папы хранится на устройстве в виде SHA-256-хеша и защищает интерфейс от случайного доступа. Это не серверная аутентификация и не шифрование данных: пользователь с техническим доступом к браузеру и его хранилищу может обойти такую защиту. Для надёжной защиты и синхронизации между устройствами нужен сервер.


ОБНОВЛЕНИЕ v13:
- В раунде две жизни: после второй ошибки раунд проигран.
- Подсказки выдаются за 10 раундов подряд без ошибок; неиспользованные подсказки сохраняются.
- Кнопка подсказки показывает количество и выделяет одну правильную пару. Использование списывает одну подсказку.
- Символ балла остаётся одинаковым в течение одной полной игры из 10 раундов.
- Добавлена кнопка «Сменить роль»; для входа в режим папы требуется пароль.
- Для обновления замените файлы на GitHub Pages; затем нажмите «Обновить» в приложении.
